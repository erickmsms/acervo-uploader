Política de privacidade – Acervo Uploader

Última atualização: 12 de outubro de 2026.

O Acervo Uploader é uma ferramenta interna de um canal do YouTube. Ela é usada apenas pela conta do próprio canal.

Quais dados o aplicativo acessa

Com a autorização do dono do canal, o aplicativo usa a YouTube Data API para enviar vídeos ao canal e editar o título, a descrição, as tags, a visibilidade e as playlists desses vídeos.

Como os dados são usados e guardados

  • O token de acesso fica salvo apenas no computador do canal e não é enviado a terceiros.
  • O aplicativo não coleta, vende nem compartilha dados de espectadores ou de outros usuários.
  • Os dados obtidos das APIs do Google são usados somente para publicar e organizar os vídeos do próprio canal.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

O aplicativo usa os Serviços de API do YouTube; veja os Termos de Serviço do YouTube e a Política de Privacidade do Google.
